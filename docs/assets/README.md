# README artwork

`parlance-cover.png` is a 1920 × 810 cover for the repository README.

It uses the current Parlance logo supplied by the project owner, preserved in
`jav-parlance-logo.png`. The cover centers the logo artwork and blends its black
background into a dark canvas, with blue and violet accents from the logo.
Typography uses the bundled Google Sans Flex typeface under its
[OFL](../../apps/desktop/src/assets/fonts/OFL.txt).

The English/Spanish conversation is manually written sample text. The artwork is
an illustrative composition, not a screenshot, model benchmark, or evidence of a
live translation session. Product capabilities and support limits are described
as searchable text in the main [README](../../README.md).

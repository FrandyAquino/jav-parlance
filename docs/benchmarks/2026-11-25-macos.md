## Inference

The real-time JFK fixture benchmark with Whisper Base Q8 produced WER 0.045 (one substitution), RTF 1.03,
three final segments and 22 updates on a warm run. Model load was 714 ms; final latency p50 79 ms / p95 125 ms.
An initial run spent 56.8 s initializing/compiling Metal shaders. The optional Metal tensor API probe failed and
automatically disabled tensor operations; ordinary Metal inference continued. A diagnostic run with
`GGML_METAL_TENSOR_DISABLE=1` loaded in 325 ms, but shader caches were already warm, so this does not establish
that tensor probing caused the entire cold delay. No permanent tensor-disable setting was introduced.

The Qwen 2B CLI translation test started the official sidecar with GPU offload in 14.4 s and translated
“Can we finish the proposal by Friday?” to “¿Podemos finalizar la propuesta antes del viernes?”. Cold total
1,140 ms; warm total 211 ms. These are local diagnostic measurements made while builds were running,
not isolated performance certification.

## Packaged build and review fixes

A universal `.app` was built and inspected as a fat Mach-O with arm64 and x86_64 slices. A 13 MiB universal
DMG was produced with `CI=true`; this skips Finder decoration, which timed out in interactive bundling.
Release linking explicitly includes Xcode's clang runtime for native `@available` helpers.

Packaged development acceptance displayed installed models, native sources, transcript, translation and copilot.
The first Cmd+Q test reproduced a missing session end time in SQLite. The corrected path adds bounded cleanup
on native Exit and drains pending translations before stopping the model. The rebuilt, installed universal
app passed the Cmd+Q check: session 3 had a non-null end time, three final lines and three translations after
process exit. No Parlance llama-server remained. History was restored to its original disabled setting.

A proposed tap-only aggregate was tested and rejected: it received no callbacks on this host. The final adapter
retains the physical output clock and excludes its input buffers, so a headset's microphone is not mixed into
system/app capture. Physical USB interfaces remain a separate hardware acceptance item.

The final callback-buffer configuration was re-probed with system audio: 492,544 samples, 320,428 nonzero,
peak 0.652475, zero drops. The final native source tests (8) and workspace clippy with `-D warnings` passed.
The installed universal app includes its audio-purpose strings and entitlement and passes
`codesign --verify --deep --strict` with an ad-hoc identity. No Developer ID/notarization is claimed.

The native source picker was exercised with microphone as primary and then restored to system audio; it
hid the secondary microphone control for the microphone-only selection. The complete code review finished
with no actionable findings after lifecycle and stale-refresh fixes. Review is source evidence, separate from
these runtime checks.

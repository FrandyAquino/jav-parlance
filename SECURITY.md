# Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/FrandyAquino/jav-parlance/security/advisories/new)
for security issues. Do not post exploit details, credentials, meeting transcripts,
or private audio in a public issue.

Include the affected commit or build, operating system, reproduction steps,
expected impact, and a minimal proof of concept using synthetic data where possible.
Keep any testing limited to systems and data you control.

Parlance is in early development and has no published stable releases. Security
fixes target the current development code; older commits do not have a separate
maintenance or backport policy. Reports are reviewed by the maintainer, without
a guaranteed response time.

For ordinary bugs, use the [bug report form](https://github.com/FrandyAquino/jav-parlance/issues/new?template=bug_report.yml).
See [security and privacy architecture](docs/security.md) for the threat model.

# TypeScript conventions

- Strict TS (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, `verbatimModuleSyntax`). Use
  `import type` for types (ESLint `consistent-type-imports`).
- IPC types come from `@/bindings` (generated by `cargo test`). Never edit `src/bindings/*`; change the Rust type in
  `crates/protocol` or `crates/domain` instead.
- Call the backend only through `src/lib/ipc.ts`. Commands returning `()` are wrapped as `Promise<void>`.
- Show `IpcError.message` via `errorMessage()`; branch on `IpcError.code`, never on message text.
- Session state is derived only from `SessionEvent`s in `store/session.ts` (pure `reduceSession`, unit-tested). Keep
  the reducer pure and bounded (`MAX_ROWS`, suggestions, notices).
- Zustand selectors pick the smallest slice (`useSession((s) => s.level)`) so 20 Hz level updates do not re-render
  the transcript.
- Use the `ui/` primitives and token classes (see `docs/design-system.md`); icon-only buttons need `aria-label`.
- Keyboard shortcuts go through `useShortcuts` in `App.tsx`; mention them in the tooltip.
- Extension: validate every `chrome.runtime` message with the guards in `lib/messages.ts` / `lib/wire.ts`; mirror
  Rust constants in `lib/constants.ts`; keep the AudioWorklet allocation-light; DSP code stays in `lib/` and is
  vitest-covered.
- Run `pnpm -C <app> typecheck && pnpm -C <app> lint && pnpm -C <app> test` before finishing.
